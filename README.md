# LML Connect

Estructura inicial creada a partir del prompt maestro del proyecto.

## Estado actual

Esta entrega contiene únicamente la estructura organizada de carpetas y archivos de la FASE 1.
Los archivos están preparados para recibir el código real en las siguientes fases.

## Módulos principales

- `src/routes/`: páginas y rutas de la aplicación.
- `src/lib/components/`: componentes reutilizables de interfaz.
- `src/lib/services/`: acceso a datos y lógica de Supabase.
- `src/lib/types/`: tipos TypeScript.
- `src/lib/utils/`: utilidades como WhatsApp, Google Maps y validaciones.
- `supabase/migrations/`: migraciones SQL y políticas de seguridad.
- `public/`: recursos públicos.

## Importante

La base de datos real de Supabase se integrará posteriormente. No se han agregado datos ficticios.
